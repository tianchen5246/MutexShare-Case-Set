# 用例说明

本目录包含 5000 个测试用例，时序库统一使用 `lib/` 目录下的 `gscl45nm.lib`。

每个用例对应 `case/` 下的一个独立目录（`case_0001/` ~ `case_5000/`），目录内包含 RTL 文件与配套 SDC 文件：

- `tc.v`：RTL 设计文件，module 名统一为 `tc`
- `tc.sdc`：配套时序约束文件，包含时钟定义（`vclk`，周期 1.0ns）、输入/输出延迟约束（0.2ns）及各选择信号（`sel_*`）的逐信号/逐 bit input delay（取值范围 0~0.4ns）

用例需在以下两种场景下均达成相应技术诉求：

1. **无时序约束**：不读入 SDC 文件
2. **有时序约束**：读入配套 SDC 文件（`tc.sdc`）
